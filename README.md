# GSK Step Up Career Challenge Portfolio

This repository contains my completed solutions for the GSK DigData “Step Up” Career Challenge, completed using multiple analytical approaches and technologies.

The challenge focuses on analysing and presenting data from a theoretical oncology clinical trial for a fictional treatment called **Miraculon-B**. The aim was to investigate treatment effectiveness, identify patient sub-groups that benefit most, and communicate findings clearly to both technical and non-technical audiences. :contentReference[oaicite:0]{index=0}
