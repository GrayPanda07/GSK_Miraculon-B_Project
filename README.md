# GSK Miraculon-B Step Up Project
---

## About the Challenge

The GSK DigData Step Up Career Challenge simulates a real-world pharmaceutical analytics project focused on clinical trial analysis and decision-making.

Participants can choose between two pathways:

## Challenge A – Clinical Data Analysis

Analyse clinical trial data to determine whether Miraculon-B performs better than the current standard of care.

Tasks included:

* Data cleaning and preprocessing
* Removing duplicate records
* Filtering paediatric patients
* Handling missing values
* BMI calculation
* Merging biomarker datasets
* Exploratory data analysis
* Statistical summaries
* Data visualisation
* Optional predictive modelling
* Presentation of findings

The challenge explored:

* Treatment response rates
* Protein concentration as a predictive biomarker
* Differences between responders and non-responders
* Patient subgroup analysis

---

## Challenge B – Web Tool & Data Strategy

Design a prototype web application to help doctors evaluate the benefit-to-risk ratio of prescribing Miraculon-B.

Tasks included:

* Exploring adverse event data
* Understanding clinical trial findings
* Applying design thinking principles
* Creating wireframes and interface concepts
* Developing healthcare-focused dashboard ideas
* Presenting findings and design decisions

The challenge focused on communicating complex clinical insights in a clear and user-friendly way for healthcare professionals.
